## About Me

Software Engineer with **6+ years of experience** designing and building scalable backend systems, data-intensive APIs, and modern web and multiplatform mobile applications.

My work centers on the engineering thinking behind production software: clear system design, pragmatic architecture, and decisions that hold up as products grow. I've reduced backend response times from **~30s to ~5s**, scaled REST APIs serving **4K+ daily requests** for **200+ enterprise clients**, and contributed to distributed platforms serving **~750K monthly active users**.

- **Simplicity over complexity:** Clear, maintainable architectures over clever abstractions.
- **Performance as a feature:** Latency and throughput treated as first-class product requirements.
- **APIs built to last:** Clean contracts and service boundaries designed for graceful evolution.
